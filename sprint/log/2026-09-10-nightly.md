## The two harness bugs

1. **No entry point.** `scripts/e2e.py` defines `main()` but has no `if __name__ == "__main__": sys.exit(main())`.
   Running it defines the functions and exits **0 with no output** — so every caller (this nightly, and anything in CI
   that shells out to it) sees a silent pass while testing nothing.
2. **Stale API contract.** With the entry point restored, line 97 raises
   `TypeError: 'NoneType' object is not subscriptable`: it reads `ids.get("ids")`, but `POST /api/import/path`
   in `rapport/server.py:179` returns `{"imported": [...]}`.

Fix (both lines, not applied here — the nightly only commits its log):

```python
rid = ((ids.get("imported") or ids.get("ids")) if isinstance(ids, dict) else ids)[0]
...
if __name__ == "__main__":
    sys.exit(main())
```

Reproduce: `cd ~/.rapport-sprint/repo && ./scripts/e2e.py; echo $?` → prints nothing, exits 0.
