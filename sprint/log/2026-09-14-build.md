## Built: a summary template per source — [#15](https://github.com/Nirmaypanchal/rapport/pull/15)

A library holds two or three kinds of recording at once, and which kind a recording is usually follows from where it
came from. Rapport had one default template for all of them, so the shape of the summary was the one thing the app
knew enough to guess and didn't.

- **`summarize.template_for()` is the chain in one place**: the recording's own template (a pick in the Summary tab,
  or the shape its last summary was written in) → the default for its source → the one default in Settings. The
  worker and the Summary tab resolve the same order; `frontend/src/lib/api.ts` has the second half of it as
  `defaultTemplateFor()`.
- **The decision worth naming**: what to do with a per-source entry whose template no longer exists. `get_template`
  answers `meeting` for an unknown id, which would quietly demote the default the user *did* choose, so
  `template_for` ignores the stale entry and falls through to that default instead. Same for `custom` with no prompt
  written. `PUT /api/settings` also refuses to store an id that does not exist, but the resolver does not rely on
  that — `settings.json` is a file a user can edit.
- **Nothing is set for you.** `summary_template_by_source` is empty by default, so a library that never opens the
  setting behaves exactly as before, and no existing summary is rewritten. The source default decides the *next*
  summary of a recording that has never had one; a recording that has one keeps its own template.
- **Settings lists the sources you actually import from**, not the nine Rapport can import from: `GET
  /api/summary/templates` now returns `by_source` and `sources` (from `db.source_counts()`, most first), plus any
  source carrying an override even at zero recordings so it can be seen and cleared.
- The Summary tab says "Your default for Apple Voice Memos" under the picker when the source is the reason — the
  only place the effect of a setting on another page would otherwise be invisible.
- `sourceLabel` moved from `recordings/detail.tsx` to `lib/format.ts`: a pure formatter with a second caller now.
