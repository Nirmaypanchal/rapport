## Decisions from the table

1. **A release gate with no timeout is a gate that can close forever.** Release keeps the nightly gate, but it now
   expires: if the newest `sprint/log/*-nightly.md` is more than seven days old and macOS CI is green on the exact
   commit, Release may tag a 0.x release provided the release notes say plainly that the on-device end-to-end test has
   not run since that date, and an open `needs-human` issue exists for the silent nightly. Shipping unverified and
   saying so beats never shipping. Recorded in `sprint/decisions.md`.
2. **Release escalates on the first run a gate blocks it**, in the same run, not after a second agent notices. "It will
   probably run tonight" is not a reason to withhold a human's attention.
3. **Research must leave the board with a week of work on it, not three days'.** At least seven Ready items under Now,
   and the "promote at most two" cap is gone — it was written for a weekly Build, not a daily one.
4. **When Now is blocked, Build does not starve.** It takes the first unblocked item from Next that is specified enough
   to build, and says so in its log. Build was already reasoning this way on 09-13; it is the rule now.
5. **A resolved escalation gets closed by whoever can prove it is resolved.** Waiting for the owner to close an issue
   they have already acted on stalled the loop for four days. An agent with direct evidence comments with that evidence
   and closes it; Research still owns the sweep and the file move. This is a role-file change only — the Escalation
   section of AGENTS.md is untouched, and it does not say the owner is the only one who may close.
6. **The Community agent's quiet runs get cheap, and its listening gets complete.** A verified-quiet run is a
   three-line log. In exchange, "I could not check Discussions" is no longer acceptable: `WebFetch` reads them.
7. **An absence must be detectable by something other than an agent's memory.** A watchdog for the nightly's silence is
   on the board rather than in a role file, because a workflow will notice on a Sunday and an agent might not.
