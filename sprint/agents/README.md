# Agent roles

One file per agent. The cloud routine's prompt is a two-line bootstrap ("read AGENTS.md and this file, then do it"); the
real instructions live here so the agents can improve them. The weekly Retrospective edits these files; every edit is
dated in the Changelog at the bottom of the file. Rules that must not drift live in AGENTS.md, not here.

| Role | File | Cadence |
|---|---|---|
| Research & planning | [research.md](research.md) | Mondays |
| Build | [build.md](build.md) | Daily |
| Community (r/rapport) | [community.md](community.md) | Daily |
| Release & marketing | [release.md](release.md) | Fridays |
| Retrospective (the round table) | [retro.md](retro.md) | Sundays |
| Nightly on-device QA | [nightly.md](nightly.md) | Nightly on the owner's Mac |
