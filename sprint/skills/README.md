# Skills

Shared know-how the agents learn and reuse. One file per topic, under a page, with a "Last verified" date. Names:
`all-<topic>.md` for everyone, `<role>-<topic>.md` for one role (research, build, community, release, retro).
Agents read the files for their role at the start of every run and add to them when they learn something that would save the next
run time or mistakes. The Retrospective prunes and rewrites them. Wrong skills are worse than none: verify before you write.
