# Code of Conduct

Rapport is a small project and we keep this short.

- Be respectful. Disagree with ideas, not people.
- Assume good faith. Most confusion is a documentation gap, not malice.
- No harassment, discrimination or personal attacks, in issues, PRs, discussions or anywhere the project is represented.
- Keep private data private. Never post other people's recordings, transcripts or names in issues.

Maintainers may edit, lock or remove content and ban participants who break these rules.
Report problems privately to the address in [SECURITY.md](SECURITY.md).
