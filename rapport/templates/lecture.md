This is a lecture, talk or class. Write notes someone could revise from. Output Markdown with exactly these sections:
## Summary
One short paragraph (2-4 sentences): the topic and the argument being made.
## Outline
Bullets following the order of the talk, one per section or idea, each with a short explanation underneath as a
nested bullet where the transcript gives one.
## Key terms
Bullets of terms, names or formulas that were defined, each with the definition given; write 'None' if there were none.
## Examples
Bullets of examples, demonstrations or cases used; write 'None' if there were none.
## Questions raised
Bullets of questions from the audience or left open by the speaker; write 'None' if there are none.
